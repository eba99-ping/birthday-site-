Яаж мэндчилгээ хийх вэ?

Доорх зургаан зүйлийг дарааллаар нь хийгээрэй. Товч бүр дээр юу хийхийг нь бичсэн байгаа. 😊

📱1

Эхлээд нэвтэрнэ

“Нэвтрэх” дээр дарна. Утасны дугаар, өөрийн PIN кодоо бичнэ. Шинэ хүн бол “Бүртгүүлэх”-ийг дарна.

🎁2

Багцаа сонгоно

“Багц сонгох” дээр дарна. Normal, Premium, Advanced гурваас дуртайгаа сонгоно.

💳3

Төлбөрийн кодоо бичнэ

Сонгосон багцынхаа төлбөрийг хийнэ. Дараа нь танд өгсөн нууц код-ыг бичнэ. Нэг code зөвхөн нэг website-д нэг удаа ажиллана.

✍️4

Мэндчилгээгээ бичнэ

Хүнийхээ нэр, мэндчилгээний төрөл, хэлэх үгээ бичнэ. Бичих бүрд жижиг website нь шууд өөрчлөгдөнө.

📸5

Зураг, бичлэгээ нэмнэ

“Зураг сонгох” дээр дараад гоё дурсамжуудаа нэмнэ. Хүсвэл бэлэг, торт, цэцгийн дүрсээ сонгоно.

✅6

Шалгаад дуусгана

“Preview Website”-ээр бүх хуудсаа үзнэ. Таалагдвал “Finalize + Link” дарна. Link зөвхөн багцын code идэвхжүүлсэн үед гарна.

💡 Санаарай: Алдаа гаргасан ч айх хэрэггүй. “← Буцах” товчоор буцаад дахин засаж болно.
